# Security policy

## Supported version

Security updates target the latest release on `main`.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not
open a public issue containing credentials, exploitable file samples, personal
data, or detailed reproduction steps for an unpatched vulnerability.

Include:

- affected version or commit;
- impact and attack prerequisites;
- minimal reproduction;
- suggested mitigation, if known.

## Data handling

RiverSort AI processes uploaded media in a temporary workspace and removes it
after analysis. Operators remain responsible for the lawful collection and use
of uploaded media. Do not upload media containing personal or confidential
information unless you are authorized to process it.

Model weights and downloaded archives must be verified against their published
SHA-256 checksum before use.
